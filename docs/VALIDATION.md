通用模板与原稿区别：保留首屏语言、地图侧栏、城市/逐日叙事和时间线联动；默认无街道底图，未通用化原稿美食独立图层、个别定制分类和站点特殊逻辑。原始 HTML 在 assets/reference-original.html，保留用于审美参考，里面的历史数据不得直接当作新行程事实。

当前输入一次生成网页和摘要，旧 trip-card 导出为单向桥接；不支持实时双向同步、跨设备草稿、协作编辑、订单预订或自动路线优化。

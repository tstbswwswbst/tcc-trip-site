# travel-guide-site · 旅游攻略网站生成器

> 一句话：告诉 AI「我想从哪去哪玩几天」，它还你一个**能直接分享到微信**的精美旅游攻略网站。

[在线示例：江南行旅（杭州·乌镇·苏州 8 日，由本 skill 模板生成）](https://travel-guide-demo-2026.surge.sh)

## 它能做出什么

一个单文件 HTML 攻略网站，包含：

- 🗺️ **高德实景交互地图** —— 所有景点/美食/酒店/车站标注在地图上，城际交通虚线、每日路线折线、快捷定位按钮
- 🧭 **一键导航** —— 每个地点都有「高德地图导航」链接：PC 打开网页版导航，手机直接唤起高德 App（GCJ-02 精准定位）
- 📅 **逐日行程时间轴** —— 每天几点去哪吃什么，点开有详情弹窗
- 🚄 **交通方案卡片** —— 去程/城际/返程，高铁大巴打车多方案比价
- 🍜 **美食指南** —— 按城市列出老字号与招牌菜，地图上独立图层
- 💰 **预算表** —— 分项 low/high 区间，总计一目了然
- 🧳 **行李清单 + 天气提示 + 雨天备选** —— 手机上看着查的实用板块

设计上：衬线标题 + 暖纸底色 + 城市专属色系统 + 山峦剪影 Hero，移动端完整适配。**美观是第一优先级**——每种目的地气质配一套主题（水乡青 / 古都红 / 海滨蓝 / 大漠沙 / 雪国灰…）。

## 用户只需要说

```
我想做一个旅游攻略网站：从成都出发，去大理和丽江玩 5-6 天，2 个人，预算有限
```

可选的个性化指令：

| 你说 | 它做 |
|------|------|
| "预算有限" | 多推免票景点（公园/历史街区/夜景），收费项标为可选 |
| "主要想打卡拍照" | 选视觉地标，文案给拍照机位建议 |
| "带着老人小孩" | 每天景点更少，午休写进时间轴 |
| "吃货行程" | 每城 6-10 家餐厅，正餐节点排进每日时间轴 |

## 快速开始（三选一）

### ① 在 TRAE / WorkBuddy / 任何支持 Skill 的 AI 里

把本仓库放进技能目录（TRAE 为 `.trae/skills/travel-guide-site/`），然后直接对话：

> 帮我做一个攻略网站：出发地 X，目的地 Y 和 Z，玩 N 天

AI 会自动：选点 → 找 GCJ-02 坐标 → 填数据 → 校验 → 部署，最后给你一个可分享的网址。

### ② 在 Claude / GLM / 任意大模型里

把 `SKILL.md` + `references/` 四个文档发给它作为上下文，模板 `assets/template.html` 作为附件，然后说同样的需求。

### ③ 手动（不用 AI）

复制 `assets/template.html` 为 `index.html`，用任意编辑器改其中 `var TRIP_DATA = {...}` 数据区（字段说明见 `references/data-schema.md`），浏览器打开即用。

## 设计原则

1. **美观第一** —— 第一眼的观感决定一切；模板固化了字体层级、留白节奏、卡片语言，AI 只选主题、不碰样式
2. **地图零空白** —— 高德瓦片配置受 verify.js 保护；Leaflet 加载失败时整站优雅降级，不会白屏
3. **导航零错位** —— 坐标必须 GCJ-02 火星坐标系（拾取器直取 / WGS-84 公式转换），verify.js 用中国经纬度范围拦截颠倒错误
4. **数据诚实** —— 查不到的票价写区间+"以现场为准"，不编精确数字
5. **随手部署** —— 单文件无构建，三平台任选，排错表齐全

## 常见问题

**Q：地图打开是灰色的？**
瓦片配置被改动或断网。对照 `references/amap-map.md` 的空白排查表，verify.js 也会拦截瓦片配置错误。

**Q：导航定位偏了 500 米左右？**
用了 WGS-84 坐标（GPS/Google/OSM 原始坐标）。用高德坐标拾取器重新取点，或用文档里的转换公式。

**Q：怎么改颜色/标题/城市？**
全部在 `TRIP_DATA` 里：`theme` 换配色（7 套预设），`meta` 改标题，`cities` 换城市。不改任何代码。

**Q：部署哪个好？**
小白要快：Netlify Drop（浏览器拖文件夹）；要长期稳定：GitHub Pages；电脑有 Node：Surge 一条命令。详见 `references/deployment.md`。

**Q：地图数据准确吗？**
瓦片是高德官方服务，与高德 App 同源；景点坐标由 AI 检索填写，verify.js 校验范围与一致性，建议出行前在高德 App 里抽查关键导航点。
